# VTB SME Referral Program

Продуктовый кейс по redesign реферальной программы Банка ВТБ для клиентов малого и среднего бизнеса.

Цель проекта — разработать новую модель referral-программы, которая учитывает реальные потребности ИП и ООО, повышает привлекательность программы для действующих и новых клиентов и при этом сохраняет экономическую эффективность для банка.

Проект объединяет анализ рынка, Customer Development, сегментацию аудитории, генерацию и приоритизацию продуктовых инициатив, финансовую модель, антифрод-механики и UX-прототип.

## Задача

Разработать обновлённую реферальную программу для клиентов малого и среднего бизнеса ВТБ.

Новая программа должна:

- мотивировать действующих клиентов рекомендовать банк;
- создавать реальную ценность для привлечённого бизнеса;
- учитывать различия между ИП и ООО;
- снижать стоимость привлечения клиента;
- повышать активность новых клиентов после регистрации;
- снижать риск мошенничества;
- поддерживать долгосрочный LTV клиента.

## Контекст

Реферальная программа для B2B значительно отличается от referral-механик для физических лиц.

Для предпринимателя важна не только денежная выплата.

При выборе банковских услуг представители МСБ обращают внимание на:

- стоимость обслуживания;
- комиссии;
- прозрачность;
- качество поддержки;
- удобство приложения;
- дополнительные бизнес-сервисы;
- инструменты, которые помогают сократить операционные расходы.

Поэтому задача проекта заключалась не просто в увеличении денежного бонуса, а в создании набора преимуществ, которые закрывают реальные потребности бизнеса.

## Ключевые рыночные выводы

Исследование показало несколько повторяющихся практик.

### Бесплатное обслуживание

Один из наиболее распространённых способов привлечения бизнеса.

Для нового клиента это снижает барьер первого использования банковского продукта.

### Денежные выплаты

Прямые выплаты остаются понятной и универсальной механикой.

### Многоступенчатые вознаграждения

Часть вознаграждения может выплачиваться после выполнения клиентом определённых условий.

Например:

```text
Открытие счёта
↓
Начало использования
↓
Достижение определённого оборота
↓
Дополнительное вознаграждение
```

Такая система стимулирует не только регистрацию, но и реальное использование банковского продукта.

### Партнёрские бонусы

Дополнительную ценность могут создавать сервисы, которыми бизнес уже пользуется:

- продвижение;
- найм;
- бухгалтерия;
- электронный документооборот;
- другие B2B-инструменты.

## Основные боли аудитории

### ИП

Для индивидуальных предпринимателей были особенно актуальны:

- высокие комиссии;
- нехватка средств на старте;

- длительность отдельных процессов;
- необходимость снижать операционные расходы;
- потребность в простом банковском сервисе.

### ООО

Для компаний более заметными становятся:

- расходы на поиск сотрудников;
- необходимость работать с большим объёмом данных;
- расширение клиентской базы;
- дополнительные инвестиции;
- масштабирование операций;
- потребность в комплексном банковском обслуживании.

## Общие потребности МСБ

Исследование показало важность:

- низких комиссий;
- прозрачных условий;
- качественной поддержки;
- удобного digital-интерфейса;
- сокращения лишних взаимодействий с банком;
- инструментов для продвижения бизнеса;
- снижения операционных расходов.

Также выяснилось, что реферальные программы для бизнеса используются значительно реже, чем аналогичные программы для физических лиц.

Это создаёт пространство для redesign продукта.

## Сегментация

Программа была разделена сразу по двум параметрам.

### Тип бизнеса

```text
ИП
ООО
```

### Роль пользователя

```text
Реферер — существующий клиент,
который приглашает нового пользователя.

Реферал — новый клиент,
которого пригласили в банк.
```

Таким образом можно создавать разные ценностные предложения для четырёх сценариев:

```text
ИП → ИП
ИП → ООО
ООО → ИП
ООО → ООО
```

## Генерация инициатив

Для новой referral-программы были рассмотрены:

1. бесплатный USB-токен для электронной подписи;
2. отсутствие комиссии на первые платежи;
3. повышение уровня тарифа РКО;
4. партнёрство с Яндекс Бизнес;
5. скидка на Яндекс 360;
6. скидки на размещение вакансий;
7. бонусы для сотрудников;
8. повышенный cashback.

## Приоритизация

Инициативы сравнивались по двум основным критериям:

- привлекательность для пользователя;
- стоимость реализации.

В результате ключевыми направлениями стали решения, которые одновременно:

- закрывают существующую боль бизнеса;
- понятны пользователю;
- позволяют получить ощутимую выгоду;
- остаются экономически приемлемыми для банка.

## Финальная концепция

Новая программа строится не вокруг одного универсального бонуса.

Вместо этого создаётся система персонализированных преимуществ в зависимости от:

- типа бизнеса;
- роли пользователя;
- тарифа;
- активности привлечённого клиента.

## Механики для реферера

Действующий клиент может получить:

### Повышение тарифа

Бесплатное повышение грейда тарифа на один месяц при сохранении текущей стоимости обслуживания.

Такой бонус позволяет существующему клиенту протестировать более функциональный пакет.

### Денежное вознаграждение

Размер вознаграждения зависит от типа привлечённого бизнеса.

Дополнительная выплата становится доступна после достижения рефералом определённого оборота.

Это связывает reward не только с регистрацией, но и с активностью нового клиента.

## Механики для реферала

Новый пользователь получает набор преимуществ, который помогает снизить барьер начала работы с банком.

### Бесплатное обслуживание

Возможность протестировать банковский продукт без дополнительных затрат.

### Продвижение бизнеса

Скидка на инструменты Яндекс Бизнес.

Механика особенно актуальна для компаний, которым необходимо привлекать клиентов.

### Электронная подпись

Для части пользователей предлагается бесплатный USB-токен для ЭЦП или альтернативная денежная выплата.

### Найм

Для ООО была предложена скидка на размещение вакансий на hh.ru.

## Партнёрство с Яндекс Бизнес

Одной из ключевых инициатив стало предоставление скидки на продвижение.

Причина выбора:

многие представители МСБ нуждаются не только в банковском обслуживании, но и в инструментах для привлечения клиентов.

Поэтому referral-программа становится способом предоставить бизнесу дополнительную практическую ценность.

## CustDev инициатив

После формирования инициатив потенциальным пользователям предложили оценить их по шкале от 1 до 10.

Наиболее высокие оценки получили:

- продвижение в Яндекс Картах;
- повышение тарифа РКО;
- скидка на интернет-продвижение.

CustDev использовался как дополнительный инструмент проверки продуктовых гипотез перед формированием финального предложения.

## Многоступенчатое вознаграждение

Для повышения качества привлечённых пользователей была разработана многоступенчатая система.

```text
Реферер приглашает клиента
↓
Клиент открывает счёт
↓
Получает первый набор преимуществ
↓
Начинает пользоваться счётом
↓
Достигает необходимого оборота
↓
Реферер и / или реферал получают дополнительный бонус
```

Это позволяет стимулировать не просто acquisition, а дальнейшую активность клиента.

## Anti-Fraud

Отдельный блок проекта был посвящён снижению риска злоупотреблений.

Одна из механик — проверка реферала по ИНН.

Логика:

```text
Ввод ИНН
↓
Запрос в anti-fraud систему
↓
Проверка данных
↓
Скоринговая оценка
↓
Оценка рисков
↓
Решение
```

Проверка может использовать:

- банковские базы;
- государственные реестры;
- скоринговые системы;
- анализ подозрительного поведения.

## Дополнительные anti-fraud ограничения

Также были предложены:

- ограничение количества привлечённых клиентов;
- специальные правила для аффилированных компаний;
- привязка части вознаграждения к обороту;
- многоступенчатая выплата бонуса.

Это помогает снизить мотивацию создавать фиктивные регистрации исключительно ради получения reward.

## Unit Economics

В рамках кейса была рассчитана стоимость привлечения нового клиента.

### ИП

Прогнозная стоимость привлечения:

**≈ 10 004 ₽**

### ООО

Прогнозная стоимость привлечения:

**≈ 11 879 ₽**

Таким образом, стоимость привлечения одного нового клиента в разработанной модели остаётся ниже 12 000 ₽.

## Экономика клиента

В модели использовались следующие прогнозные показатели:

- **средняя прибыль с одного клиента МСБ — около 15 760 ₽ в месяц**;
- **LTV1Y — около 189 126 ₽**.

Показатели являются результатом финансовой модели кейса и зависят от её предпосылок.

## Потенциальный эффект

В расчётной модели новая referral-программа потенциально позволяет:

- увеличить количество рефералов;
- привлекать более активных пользователей;
- сохранять CAC на контролируемом уровне;
- повышать LTV привлечённых клиентов;
- увеличить использование продуктов банка;
- снизить уровень referral fraud.
